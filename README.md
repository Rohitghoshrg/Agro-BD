# Agro-BD

Agriculture support mobile application that gives farmers agricultural information and support, with a user-friendly interface and database integration for storing and retrieving agricultural data.

## Tech

- Android Studio, Java
- Firebase / MySQL

## In this repo

Project files and documentation for AgroBD, including the Agro-Bridge document, the Android problem-definition document, the project proposal, and TaskTrail.
